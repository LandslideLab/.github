# LANDSLIDE ⛰️

> **Weird ideas, made real.**

LANDSLIDE is an open community for people who like building strange, ambitious things — especially around **multi-agent systems** and **human-machine collaboration**. Visual work is welcome too: generative art, interactive experiments, anything that looks as good as it runs.

If you have a crazy idea, or just want to help build someone else's, this is the place.

---

## 🚪 Who can join?

**Anyone.** No experience requirements, no interviews, no gatekeeping.

This community is fully open — newcomers, students, hobbyists, researchers, artists, everyone is welcome. You don't need a project of your own to join; you can start by helping with an existing one.

## ✋ How to join

It's one step:

1. **Open an issue in this repo** with the title:
   ```
   Join request: <your GitHub username>
   ```
2. (Optional but fun) tell us what you want to build or explore.
3. A maintainer will invite you. That's it 🎉

Your membership is public by default; you can set it to private anytime in your org settings.

## 🧪 What we do

- **Multi-agent systems & agent governance** — e.g. [LANDSLIDE/Sphinx](https://codeberg.org/LANDSLIDE/Sphinx), a human-in-the-loop agent approval demo with MCP + REST transports
- **Human-machine collaboration** tooling and experiments
- **Visual / generative works** — art that is code, code that is art
- **Whatever weird thing you bring to the table**

## 🌱 Ground rules

- Be kind. Be curious. Give credit where it's due.
- Everything in this org is open source — that's the point.
- FOSS-friendly mirror: [codeberg.org/LANDSLIDE](https://codeberg.org/LANDSLIDE)

## 🚀 Getting started

1. Join via the issue above.
2. Introduce yourself in an issue or discussion.
3. Find something that sparks you — or open an issue with your own idea.
4. Build. Break. Learn. Repeat.

Let's make something strange.
